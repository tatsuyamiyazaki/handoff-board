# 08. ポーリング自動更新 + レーン件数

Type: AFK ／ Source: [docs/prd.md](../prd.md)（Stories 29, 30）

## What to build

`useBoard` を TanStack Query で実装し、10〜15秒間隔のポーリングでボードを自動更新する（手動リロード不要）。各レーンの先頭に件数を表示する。

## Acceptance criteria

- [ ] 10〜15秒間隔でボードが自動再取得される
- [ ] 他クライアント（人間/AI/ディスパッチャー）の変更がポーリングで反映される
- [ ] 各レーン先頭に正しい件数が表示される
- [ ] ポーリングのフックに対するテストが緑
